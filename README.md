# Give the Vehicle a Mind

A high-fidelity automotive HMI concept exploring how generative AI can be embedded directly into existing vehicle workflows at the point of driver intention.

## Overview

This project investigates a context-aware in-car AI system that combines route, ETA, traffic, calendar, and behavioural context to offer low-distraction next-best actions when timing pressure becomes meaningful.

Instead of adding another chatbot or AI tool to the car, the concept focuses on **workflow-native support** inside the vehicle itself.

## Core idea

When traffic affects a meaningful commitment, the vehicle understands the context and helps the driver with the next best action, for example:

- send a delay message
- join a meeting remotely
- reschedule
- share location
- reduce information load in stressful moments

## Prototype

The prototype is built as a **state-driven HMI simulation** with:

- **React** for UI rendering
- **JSON** for scenario data
- **JavaScript** for scenario playback and simulation logic

It demonstrates both:
- **context awareness**  
  such as work commute vs home commute behaviour
- **delay management scenarios**  
  such as late for meeting, late home, late reservation, tiredness, and cabin discomfort

## Why this matters

In automotive, poor interaction design is not just frustrating — it can become dangerous.  
This concept explores how AI can reduce cognitive friction and phone reliance instead of creating another layer of distraction.

## Project focus

- context-aware automotive UX
- low-distraction AI integration
- workflow-embedded support
- bounded autonomy
- premium in-car experience
- emerging technology in infotainment / HMI

## Status

High-fidelity concept prototype developed and evaluated through user research and UX testing.
